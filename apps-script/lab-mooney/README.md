# ฟีดสดผลทดสอบ Mooney สำหรับ MNP LAB

Google Apps Script (Web App) สำหรับสเปรดชีต **Mooney_Test_Report** — ชีตเป็นข้อมูลต้นทางและ **ไม่มีสำเนาที่ไหน**
ทุกครั้งที่หน้า MNP LAB ใน Pilot Web เปิดหรือรีเฟรช (อัตโนมัติทุก 30 วินาทีขณะแท็บเปิดอยู่) เว็บเรียก Web App นี้
สคริปต์อ่านชีต ณ ตอนนั้นแล้วตอบกลับเป็น JSON (ลิงก์ชีตไม่ใส่ใน repo)

```
เบราว์เซอร์ (admin) ──POST {token}──▶ Web App (Code.gs) ──app_lab_access + โทเค็นของผู้ใช้──▶ Supabase
                                          │                                                     │ true = admin / false = ไม่ใช่
                                          │◀────────────────────────────────────────────────────┘
                                          └─ true เท่านั้น: อ่านชีต → ตอบ JSON      อย่างอื่น: ตอบ error ไม่มีข้อมูล
```

## สิทธิ์ (ปฏิเสธไว้ก่อนเสมอ)

- เว็บแนบ **access token ของผู้ใช้ที่ล็อกอิน** ใน body สคริปต์ส่งต่อให้ Supabase ถาม `app_lab_access`
  (ฐานข้อมูลตัดสินที่ `private.can_access_lab()` — ตอนนี้ admin เท่านั้น ภายหลังเพิ่มรายชื่อ ID ที่ฐานข้อมูลจุดเดียว สคริปต์ไม่ต้องแก้)
- คืนข้อมูลเฉพาะเมื่อ Supabase ตอบ HTTP 200 และเนื้อหาเป็น `true` พอดี ทุกกรณีอื่นไม่มีข้อมูลหลุด:
  ไม่มีโทเค็น/รูปแบบไม่ใช่ JWT, โทเค็นผิดหรือหมดอายุ, ตอบ `false`, Supabase ล่ม, อ่านผลไม่ได้
- เปิด URL ของ Web App ในเบราว์เซอร์ (GET) ได้แค่ `{"ok":false,"error":"USE_POST"}`
- สคริปต์ **ไม่มี secret**: URL และ publishable key ของ Supabase ในโค้ดเป็นค่าสาธารณะ (อยู่ใน `app.js` ของเว็บอยู่แล้ว)
  และไม่บันทึกโทเค็นลง log หรือ cache
- ข้อควรรู้: โทเค็น (อายุสั้น ราว 1 ชั่วโมง) ถูกส่งไปยัง Apps Script ของบัญชี Google ขององค์กรเอง ใครแก้ไขสคริปต์นี้ได้
  ย่อมเปลี่ยนโค้ดให้เก็บโทเค็นได้ จึงควรจำกัดผู้มีสิทธิ์แก้ไขโปรเจกต์ Apps Script เฉพาะผู้ดูแลระบบ
- สคริปต์อ่านชีตด้วยสิทธิ์ของ **เจ้าของสคริปต์** ผู้ใช้เว็บไม่ต้องมีสิทธิ์เปิดชีต จึงตั้งแชร์ชีตเฉพาะคนที่ต้องแก้ไขได้
  (ไม่ต้องเปิด "ทุกคนที่มีลิงก์") ซึ่งปลอดภัยกว่า

## สิ่งที่สคริปต์ทำกับชีต

- อ่าน **ทุกแท็บที่มองเห็น** ที่แถวแรกคอลัมน์ A–H เป็น `ID, Material, TestDate, Time, Temperature, Test time, MH, MV`
  (แท็บอื่นถูกข้ามและแจ้งชื่อ)
- วันที่อ่านแบบ **วัน/เดือน/ค.ศ.** (`09/10/2026` = 9 ตุลาคม 2026) ตามที่ชีตแสดง
- คอลัมน์ `AVG MH, SD MH, AVG MV, SD MV` เป็นเซลล์ที่ merge หลายแถว สคริปต์ขยายค่าไปทุกแถวในกลุ่ม
  จึงตรงกับชีตทุกประการ ไม่คำนวณใหม่ (แท็บ `E00030S T` ไม่มีค่าเหล่านี้ จะแสดงเป็น —)
- แถวที่ข้อมูลไม่ถูกต้อง (เช่น วันที่ไม่ใช่ dd/mm/ค.ศ.) **ไม่แสดงในหน้าเว็บ** และกล่องเตือนสีเหลืองบอกแท็บ/เลขแถวให้ไปแก้ในชีต
  แถวที่เหลือแสดงตามปกติ

## ติดตั้ง / อัปเดต

1. เปิดโปรเจกต์ Apps Script ที่ deploy Web App ไว้ (ถ้าผูกกับชีต: ชีต > **Extensions > Apps Script**) วางเนื้อหา `Code.gs`
   ในโฟลเดอร์นี้ **ทับทั้งไฟล์** แล้ว Save
   - ถ้าโปรเจกต์ **ไม่ได้ผูกกับชีต** (สร้างจาก script.google.com ตรงๆ) ให้ตั้ง **Project Settings > Script properties**
     `SHEET_ID` = รหัสสเปรดชีต (ข้อความระหว่าง `/d/` กับ `/edit` ใน URL ของชีต)
2. **Project Settings** > Time zone ตั้งเป็น `(GMT+07:00) Bangkok`
3. **Deploy > Manage deployments** > ไอคอนดินสอที่ deployment เดิม > **Version: New version** > **Deploy**
   (ใช้ deployment เดิมเพื่อให้ URL เดิมที่อยู่ใน `modules/module-lab.js` ยังใช้ได้) ตั้งค่า:
   - **Execute as: Me**
   - **Who has access: Anyone** — จำเป็น เพราะเบราว์เซอร์เรียกแบบไม่มีบัญชี Google สิทธิ์จริงตรวจที่ฐานข้อมูลตามข้างบน
     (ถ้าเลือก "Anyone with Google account" เว็บอ่านคำตอบไม่ได้)
4. ครั้งแรกที่ deploy Google จะขออนุญาตสิทธิ์ (อ่านสเปรดชีต + ส่งคำขอไปภายนอก) ให้อนุญาต
5. ทดสอบ: เปิด URL ของ Web App (`.../exec`) ในเบราว์เซอร์ ต้องเห็น `{"ok":false,"error":"USE_POST"}`
   แล้วล็อกอิน Pilot Web ด้วยบัญชี admin > เมนู **MNP LAB**

> **อย่าเชื่อผลการกด Run `doPost` ในตัวแก้ไข Apps Script** เพราะตอนนั้นไม่มี `e` จริง ต้องทดสอบผ่านหน้าเว็บจริง

## ถ้าหน้าเว็บขึ้นข้อความผิดพลาด

| ข้อความในหน้าเว็บ | สาเหตุที่พบบ่อย |
|---|---|
| เชื่อมต่อชีตไม่ได้ … | ไม่มีอินเทอร์เน็ต, Web App ยังไม่ได้ deploy, หรือ "Who has access" ไม่ใช่ Anyone |
| อ่านคำตอบจากชีตไม่ได้ … โค้ดเวอร์ชันเก่า | Web App ยังเป็นโค้ดเก่า (ไม่มี `doPost`) ให้ deploy **New version** |
| ตรวจสิทธิ์กับระบบไม่ได้ชั่วคราว | Supabase ไม่ตอบ ลองใหม่ |
| อ่านข้อมูลจากชีตไม่สำเร็จ | สคริปต์อ่านชีตพลาด (ตรวจ `SHEET_ID` / สิทธิ์ของเจ้าของสคริปต์ต่อชีต) ดู **Executions** ใน Apps Script |
| หน้า "ไม่พบหน้าที่ต้องการ" | บัญชีนี้ไม่มีสิทธิ์ MNP LAB (ตามออกแบบ) |

## โควตา

Apps Script จำกัดจำนวนการเรียกต่อวันและจำนวนการทำงานพร้อมกัน (30) การใช้งานแบบ admin ไม่กี่คนและรีเฟรชทุก 30 วินาที
ขณะแท็บเปิดอยู่ (แท็บที่ซ่อนไม่ยิง) อยู่ในเกณฑ์ แต่ถ้ามีผู้ได้รับสิทธิ์จำนวนมากภายหลัง ควรทบทวนรอบรีเฟรช
(`REFRESH_MS` ใน `modules/module-lab.js`)

## ทดสอบโค้ด

ฟังก์ชันแปลงข้อมูลและ `doPost` (ทั้งกรณีได้รับอนุญาตและปฏิเสธทุกแบบ) ทดสอบด้วย stub ของบริการ Google:

```bash
node --test scripts/tests/lab-mooney-feed.test.mjs
```

ส่วนที่ต้องทดสอบบน Google จริง: `getMergedRanges`, การ deploy Web App, และการอ่านคำตอบข้ามโดเมนจากเบราว์เซอร์
