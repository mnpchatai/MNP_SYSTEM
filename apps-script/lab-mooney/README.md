# ซิงก์ผลทดสอบ Mooney ไป MNP LAB

Google Apps Script สำหรับสเปรดชีต **Mooney_Test_Report** (ลิงก์ชีตไม่ใส่ใน repo)
— ชีตนี้ยังเป็น **ต้นทางของข้อมูล** ส่วน **Supabase เป็นที่เก็บที่ Pilot Web อ่านและเป็นตัวบังคับสิทธิ์**
(ตอนนี้เฉพาะ admin เข้าโมดูล MNP LAB ได้) Pilot Web ไม่อ่านชีตตรงๆ เพราะ Google Sheets แยกไม่ได้ว่าใครเป็น admin

```
ชีต Mooney_Test_Report ──Apps Script (Code.gs)──▶ Edge Function lab-sheet-sync ──▶ RPC app_lab_mooney_import ──▶ ตาราง lab_mooney_results
                                                  (ตรวจ secret)                    (service_role เท่านั้น)           ▲
Pilot Web #/lab (admin) ──RPC app_lab_mooney_overview / app_lab_mooney_results (ตรวจสิทธิ์ทุกครั้ง)─────────────────────┘
```

## สิ่งที่สคริปต์ทำ

- อ่าน **ทุกแท็บที่มองเห็น** ที่แถวแรกคอลัมน์ A–H เป็น `ID, Material, TestDate, Time, Temperature, Test time, MH, MV`
  (แท็บอื่นถูกข้ามและแจ้งชื่อในข้อความสรุป)
- วันที่อ่านแบบ **วัน/เดือน/ค.ศ.** (`09/10/2026` = 9 ตุลาคม 2026) ตามที่ชีตแสดง ถ้ารูปแบบเปลี่ยนไปจนอ่านไม่ได้จะไม่ส่ง
  และบอกว่าแท็บไหนแถวไหนผิด (ไม่ส่งข้อมูลครึ่งๆ กลางๆ)
- คอลัมน์ `AVG MH, SD MH, AVG MV, SD MV` เป็นเซลล์ที่ merge หลายแถว สคริปต์ขยายค่าไปทุกแถวในกลุ่มก่อนส่ง
  จึงเก็บค่าตามชีตทุกประการ ไม่คำนวณใหม่ (แท็บ `E00030S T` ไม่มีค่าเหล่านี้ จะเก็บเป็นว่าง)
- ส่งทั้งหมดในครั้งเดียว ฐานข้อมูลทำงานแบบ **กระจกสะท้อนชีต**: แถวใหม่เพิ่ม แถวเดิมอัปเดต แถวที่หายไปจากชีตถูกลบ
  ทั้งหมดอยู่ในธุรกรรมเดียว (ผิดตรงไหนไม่มีอะไรเปลี่ยน) และมี **ด่านกันลบเกินครึ่ง** — ถ้าซิงก์ครั้งหนึ่งจะลบข้อมูลที่มีอยู่
  เกินครึ่ง (เช่นอ่านแท็บมาไม่ครบ) ฐานข้อมูลปฏิเสธ ต้องตั้งใจใช้เมนู **ซิงก์ (ยืนยันลบข้อมูลที่หายไป)**
- แถวถูกระบุด้วย `(ชื่อแท็บ, ID, วันที่, เวลา)` ถ้าแก้ค่าของแถวเดิม ระบบอัปเดตแถวนั้น แต่ถ้าแก้ วันที่/เวลา/ID
  ระบบมองเป็นแถวใหม่และลบแถวเก่าตามกระจกสะท้อน

## ติดตั้ง (ทำตามลำดับ)

### 1. ฐานข้อมูลและ Edge Function (ผู้ดูแลที่มีสิทธิ์ Supabase)

1. Apply migration `20261016020000_mnp_lab_mooney.sql` ตามขั้นตอน deploy ปกติของโปรเจกต์ (ต้องทำก่อนข้ออื่น)
2. สร้าง secret สุ่มยาวอย่างน้อย 32 ตัวอักษร (เช่น `openssl rand -hex 32`) แล้วตั้งเป็น Edge Function secret —
   ห้ามคอมมิตหรือส่งทางแชต:
   ```bash
   supabase secrets set LAB_SYNC_SECRET=<ค่าที่สุ่มได้> --project-ref <project-ref>
   supabase functions deploy lab-sheet-sync --project-ref <project-ref>
   ```
   (`verify_jwt = false` ตั้งไว้ใน `supabase/config.toml` แล้ว เพราะผู้เรียกคือเซิร์ฟเวอร์ Google ฟังก์ชันตรวจ secret เอง
   ถ้าไม่ตั้ง `LAB_SYNC_SECRET` หรือสั้นกว่า 32 ตัวอักษร ฟังก์ชันปิดรับทั้งหมด)

### 2. Apps Script ของชีต

1. เปิดชีต > **Extensions > Apps Script** แล้ววางเนื้อหา `Code.gs` ในโฟลเดอร์นี้แทนโค้ดเริ่มต้น
2. **Project Settings** > Time zone `(GMT+07:00) Bangkok`
3. **Project Settings > Script properties** เพิ่ม 2 ค่า:
   | ชื่อ | ค่า |
   |---|---|
   | `LAB_SYNC_URL` | `https://<project-ref>.supabase.co/functions/v1/lab-sheet-sync` |
   | `LAB_SYNC_SECRET` | ค่าเดียวกับที่ตั้งในข้อ 1 |
4. รีเฟรชชีต จะมีเมนู **MNP LAB** > **ซิงก์ไป MNP Workspace** (ครั้งแรก Google จะขออนุญาตสิทธิ์)
5. เมื่อทดลองด้วยมือผ่านแล้ว เลือก **MNP LAB > ตั้งซิงก์อัตโนมัติทุกชั่วโมง** (ถ้าซิงก์อัตโนมัติพลาด Apps Script
   ส่งอีเมลแจ้งเจ้าของสคริปต์เอง)

### 3. ตรวจผล

- ข้อความสรุปหลังซิงก์: จำนวนแถวที่ใหม่/มีอยู่แล้ว/ลบ
- เข้า Pilot Web ด้วยบัญชี admin > เมนู **MNP LAB** — บัญชีที่ไม่ใช่ admin ไม่เห็นเมนู และถ้าพิมพ์ URL `#/lab` เองก็เข้าไม่ได้
  (ฐานข้อมูลปฏิเสธ ไม่ใช่แค่ซ่อนเมนู)

## ความปลอดภัย

- **จำกัดการแชร์ของชีตเอง**: โมดูล MNP LAB ใน Pilot Web จำกัดให้เฉพาะ admin (และรายชื่อที่จะกำหนดภายหลัง) แต่ถ้าชีตตั้งแชร์เป็น
  "ทุกคนที่มีลิงก์" ใครมีลิงก์ก็เปิดอ่านข้อมูลเดียวกันได้โดยไม่ผ่านระบบนี้ ควรตั้งแชร์ชีตเฉพาะบุคคลที่ต้องเห็น
- `LAB_SYNC_SECRET` อยู่ใน 2 ที่เท่านั้น: Edge Function secret ของ Supabase และ Script Property ของชีต —
  ไม่อยู่ใน repo ไม่อยู่ใน `index.html`/`app.js` ถ้ารั่วให้สุ่มใหม่แล้วตั้งทั้งสองที่
- ใครแก้ Apps Script ของชีตได้ ย่อมอ่าน secret ได้ ให้จำกัดสิทธิ์ผู้แก้ไขชีตตามนั้น
- ข้อมูลผลทดสอบไม่ถูก log ที่ Edge Function และข้อความ error ไม่เปิดเผยค่าในแถวที่ผิด

## ทดสอบโค้ดแปลงข้อมูล

ฟังก์ชันแปลงข้อมูล (วันที่ เวลา ตัวเลข การขยายเซลล์ merge) ไม่พึ่ง Google runtime และมีเทสต์:

```bash
node --test scripts/tests/lab-mooney-sync.test.mjs
```

ส่วนที่ต้องใช้ Google runtime (เมนู, `getMergedRanges`, `UrlFetchApp`) ต้องทดสอบด้วยมือในชีตจริงหลังติดตั้ง
