# ดาวน์โหลดใบแจ้งซ่อม MT เป็น Excel (แบบฟอร์ม MT01-FM05)

Web App ของ Google Apps Script ที่ทำไฟล์ `.xlsx` ตามแบบฟอร์มในชีต **"เอกสาร"** ของสเปรดชีตระบบแจ้งซ่อม
ให้ปุ่ม **"ดาวน์โหลด Excel"** ในหน้ารายละเอียดใบแจ้งซ่อม/ใบคำร้อง MT ของ Pilot Web

- หน้าเว็บ (`modules/mt-form-export.js`) แปลงข้อมูลที่ผู้ดูเห็นอยู่แล้ว (โหลดตามสิทธิ์ RLS ของเขา) เป็นรายการ "เซลล์ → ค่า"
- สคริปต์นี้คัดลอกชีต "เอกสาร" ไปไฟล์ชั่วคราว เติมค่า แปลงช่องติ๊กเป็น ☑/☐ export เป็น `.xlsx` แล้วลบไฟล์ชั่วคราว
- สคริปต์ **ไม่อ่านข้อมูลใบใดจากชีต** และไฟล์ที่ส่งกลับมีแค่ชีตฟอร์ม ใครได้ URL ไปก็ดึงข้อมูลใบของคนอื่นไม่ได้
- **ความเสี่ยงที่ยังมี:** URL อยู่ในโค้ดหน้าเว็บที่เปิดสาธารณะ และ Web App ไม่ตรวจว่าใครเรียก คนที่ได้ URL จึง
  (1) สร้างไฟล์ฟอร์ม MT01-FM05 ที่ใส่ข้อความอะไรก็ได้ และ (2) เรียกซ้ำๆ จนกินโควตา Apps Script/Drive ของบัญชีเจ้าของได้
  ไฟล์จากระบบจึงไม่ใช่หลักฐานว่าเอกสารถูกต้อง ให้ยึดข้อมูลในระบบเป็นหลัก ถ้าพบการเรียกผิดปกติใน **Executions**
  ให้ปิด deployment (Manage deployments > Archive) แล้วสร้างใหม่
- เป็นโปรเจกต์ **แยก** จากสคริปต์ของสเปรดชีต (`apps-script/maintenance-backup/`: ซิงก์ + เติมฟอร์มจาก AG4) ไม่ต้องแก้สคริปต์นั้น

## ติดตั้ง (ครั้งแรก)

> ⚠️ **ต้องเป็นโปรเจกต์ใหม่ที่ script.google.com เท่านั้น** ห้ามวางโค้ดนี้ในโปรเจกต์ที่เปิดจากเมนู Extensions ของชีตระบบแจ้งซ่อม
> เพราะโปรเจกต์นั้นคือ Web App ซิงก์ใบแจ้งซ่อม (URL ใน `modules/module-mt.js`) วางทับแล้วการซิงก์จะหยุดทันที
> URL ของ export จึงต้องต่างจาก URL ซิงก์เสมอ (`scripts/tests/mt-form-export.test.mjs` ตรวจไว้)

1. เปิด <https://script.google.com> > **New project** ตั้งชื่อเช่น `MT01-FM05 export`
   (ใช้บัญชี Google เดียวกับเจ้าของสเปรดชีตระบบแจ้งซ่อม)
2. ลบโค้ดเริ่มต้นใน `Code.gs` แล้ววางเนื้อหา `Code.gs` ในโฟลเดอร์นี้ทั้งไฟล์ > Save
3. **Project Settings** > **Script properties** > Add: `TEMPLATE_SHEET_ID` = รหัสสเปรดชีตระบบแจ้งซ่อม
   (ข้อความระหว่าง `/d/` กับ `/edit` ใน URL ของชีต)
4. **Deploy > New deployment** > ประเภท **Web app**
   - **Execute as: Me**
   - **Who has access: Anyone** — จำเป็น เพราะเบราว์เซอร์เรียกแบบไม่มีบัญชี Google
5. อนุญาตสิทธิ์ที่ Google ขอ (สเปรดชีต, Drive สำหรับสร้าง/ลบไฟล์ชั่วคราว, ส่งคำขอภายนอกสำหรับ export)
6. คัดลอก URL ของ Web App (`https://script.google.com/macros/s/.../exec`) ไปใส่ `EXPORT_URL` ใน `modules/mt-form-export.js`
   (เปิด pull request ตามปกติ) — ถ้า `EXPORT_URL` ว่าง ปุ่มดาวน์โหลดจะไม่แสดง

ทดสอบ: เปิด URL `.../exec` ในเบราว์เซอร์ต้องเห็น `{"ok":false,"error":"USE_POST"}`
แล้วเปิดใบแจ้งซ่อมใน Pilot Web > กด **ดาวน์โหลด Excel** > เปิดไฟล์ตรวจว่าหัวฟอร์ม/โลโก้/เส้นตาราง/ช่องติ๊กครบ

> อย่าเชื่อผลการกด Run `doPost` ในตัวแก้ไข เพราะไม่มี `e` จริง ต้องทดสอบผ่านหน้าเว็บ

## อัปเดตโค้ด

วาง `Code.gs` ใหม่ทับ > **Deploy > Manage deployments** > ไอคอนดินสอที่ deployment เดิม > **Version: New version** > Deploy
(ใช้ deployment เดิม URL จึงไม่เปลี่ยน)

## แก้แบบฟอร์ม

ตำแหน่งเซลล์ผูกกับเลย์เอาต์ปัจจุบันของชีต "เอกสาร" (ช่วง A1:AJ41) แก้ข้อความ/สี/ฟอนต์ในชีตได้เลย
แต่ถ้า **ย้าย แทรก หรือลบแถว/คอลัมน์ หรือเปลี่ยนการ merge** ต้องแก้ `buildMtFormCells` ใน `modules/mt-form-export.js` ด้วย
ค่าตัวอย่างที่ค้างในชีตฟอร์ม (เช่น ID001/26) ไม่ต้องลบ ไฟล์ที่ดาวน์โหลดจะเขียนทับทุกช่องที่มีข้อมูลของใบ

## ถ้ากดแล้วขึ้นข้อความผิดพลาด

| ข้อความในหน้าเว็บ | สาเหตุที่พบบ่อย |
|---|---|
| เชื่อมต่อระบบสร้างเอกสารไม่ได้ … | ไม่มีอินเทอร์เน็ต, URL ผิด, หรือ "Who has access" ไม่ใช่ Anyone |
| สร้างไฟล์ Excel ไม่สำเร็จ … | ดู **Executions** ของโปรเจกต์: `NOT_CONFIGURED` = ยังไม่ตั้ง `TEMPLATE_SHEET_ID`, `FORM_SHEET_NOT_FOUND` = ชีต "เอกสาร" ถูกเปลี่ยนชื่อ |

## ข้อจำกัด

- ช่องลายเซ็นเติมชื่อและวันที่จากระบบ ไม่มีลายเซ็นจริง
- ตารางอะไหล่มี 4 แถว ถ้าเกิน แถวสุดท้ายเขียนว่า "และอีก N รายการ (ดูในระบบ)"
- ข้อความยาวมาก (อาการ/วิเคราะห์สาเหตุ) อาจล้นช่องเหมือนพิมพ์ในชีตเอง
- ถ้าสคริปต์ถูกตัดกลางคัน (เกินเวลา/โควตา) ไฟล์ชั่วคราวชื่อ `MT01-FM05 export ...` อาจค้างใน My Drive ของเจ้าของ ลบทิ้งได้เลย
- แต่ละครั้งที่กดใช้เวลาหลายวินาที (สร้างไฟล์ชั่วคราวใน Drive ของเจ้าของสคริปต์แล้วลบ) และนับโควตา Apps Script ของบัญชีนั้น
