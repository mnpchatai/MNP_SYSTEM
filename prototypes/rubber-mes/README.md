# RubberFlow MES (เดโม)

ระบบควบคุมการผลิตผลิตภัณฑ์ยาง 4 ขั้นตอน (ผสม → รีด → อบ → ตกแต่ง/บรรจุ) แบบ front-end ล้วน
ข้อมูลทั้งหมดเป็นข้อมูลสมมติ เก็บใน `localStorage` ของเบราว์เซอร์ กด "รีเซ็ตข้อมูลสาธิต" ที่เมนูซ้ายเพื่อเริ่มใหม่

## วิธีรัน

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # ไฟล์สำหรับ deploy อยู่ใน dist/
```

เข้าสู่ระบบ: ชื่อผู้ใช้ `admin`, `manager`, `planner`, `store`, `mixer`, `extruder`, `curer`, `finisher`, `qc`
รหัสผ่าน `demo1234` หรือ PIN `1001`–`1009` หรือบัตร `RF-1001`–`RF-1009`

## โมดูล

| โมดูล | กฎธุรกิจหลัก |
|---|---|
| ใบสั่งผลิต | ใช้ได้เฉพาะสูตรที่อนุมัติแล้ว สถานะ วางแผน → ปล่อยผลิต → กำลังผลิต ⇄ พักงาน → เสร็จสิ้น |
| สูตรยาง (BOM/PHR) | คำนวณ kg/batch จาก PHR สูตรใหม่ต้องได้รับอนุมัติจาก QC/ผู้จัดการ |
| เบิกและชั่งวัตถุดิบ | ระเบิดสูตร จัดสรรล็อตแบบ FEFO ไม่จ่ายล็อตหมดอายุหรือกักกัน ชั่งเกิน ±1.5% แล้วกดยืนยันไม่ได้ (Poka-Yoke) |
| ผสม / รีด / อบ / ตกแต่ง | ค่าที่หลุดสเปกทำให้ล็อตถูก QC Hold อัตโนมัติ, ยางต้องบ่มครบเวลา, ยางหมุนเวียนไม่เกิน 10%, นับรอบใช้งานแม่พิมพ์ |
| ส่งมอบ WIP | Gatekeeper: สถานีถัดไปเริ่มผลิตไม่ได้ถ้ายังไม่รับมอบและยืนยันจำนวนจริง |
| QC · NCR · CoA | ตัดสินล็อตที่ถูกกักกัน บันทึกผลแล็บ เปิด/ปิด NCR พร้อม 5-Why และพิมพ์ CoA |
| SPC / Cpk | I-chart (sigma จาก MR̄/d2), ฮิสโตแกรม, Cp / Cpk / Ppk |
| สืบย้อนกลับ | จากกล่องย้อนไปถึงล็อตวัตถุดิบ และจากล็อตวัตถุดิบไปข้างหน้าถึงกล่องที่ได้รับผลกระทบ |
| คลัง / แม่พิมพ์ / Audit | สต็อก FEFO, รับเข้าคลัง, ส่งมอบกล่อง, แจ้งเตือนรอบล้างแม่พิมพ์, บันทึกทุกธุรกรรม |

สิทธิ์ 9 บทบาทอยู่ใน `src/data/rbac.js` กฎธุรกิจทั้งหมดอยู่ใน `src/data/actions.js` และสเปกกระบวนการอยู่ใน `src/lib/rules.js`
